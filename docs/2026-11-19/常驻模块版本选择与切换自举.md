# 常驻模块版本选择与切换自举

## Intent · 目标

让 RX/ZX 决定引导器的模块解析批次复用、部分复用和已发布批次切换。保持包映射、模块路径诊断与跨请求寿命契约，减少相同文本的重复比较和临时位置表。

## Data · 正式调用链

`resident/modules.zig` 在输入清单装配之后准备已解析的 RX 模块。旧代码由 Zig 判断整批复用和提交状态。若同一清单末尾发现变化，旧选择流程还会从头为所有模块生成位置表。

```mermaid
flowchart LR
    Manifest[输入清单和包映射摘要] --> Compare[ZX 比较批次并确认匹配前缀]
    Compare -->|整批复用| Use[借用已校验模块视图]
    Compare -->|部分变化| Suffix[仅为剩余模块准备位置]
    Suffix --> Parse[按清单顺序解析或复用 XML]
    Parse --> Check[校验路径与 schema]
    Check --> Pending[暂存批次]
```

## Edges · 稳定顺序与资源寿命

整批复用要求包映射摘要、模块数量、有序路径与文本一致。包映射变化时重新校验批次，同时允许逐份复用未变的 XML。当批次包含已确认的前缀，后续查询从最后匹配的旧路径开始。这样相同路径的重复声明仍走原来的选择与诊断顺序。

```mermaid
flowchart LR
    Events[发布、丢弃或恢复] --> Plan[ZX 选择批次和引用动作]
    Plan --> Commit[宿主应用动作]
    Commit --> Current[当前成功批次]
    Commit --> Retire[释放无引用的批次和解析 arena]
```

ZX 选择下一批及要保留、释放的引用。Zig 继续维护实际的资源引用计数、调用 XML 解析与校验接口并释放 arena。每份 XML 记录在接管时保存其已确定的容量，释放时直接使用。初始 seed 使用等价规则。

## Answer · 验收

初始 seed 通过 14 个构建步骤，Source 引导器通过 25 个步骤。两代引导器生成同一份新规则清单，排除输入戳后 68 个文件逐字节一致。专用常驻清单覆盖整批匹配、包映射变化、末尾变更、重复路径、模块数量改变和恢复。重复路径在两版中都返回原有诊断，并复用了全部三份 XML，没有先解析重复项。

交替、混合及依赖切换场景的生成结果、活跃和留存字节、解析及复用计数和分析版本逐请求相同。连续源码失败保留相同的有效旧版本，恢复后 709 个文件同冷生成一致。交替编辑的请求中位墙钟为 49.19 → 48.35 毫秒，混合编辑为 49.34 → 49.23 毫秒，依赖切换为 52.82 → 52.43 毫秒。

固定 735 个入口，macOS arm64，Zig 0.17.0，ReleaseSmall，16 分区。三个版本均由 Source 引导器生成并执行 Source 分析与生成，三轮交错运行取中位数。上一阶段与候选的 11,758 个输出及 v18 唯一性缓存载荷逐字节一致，输入戳随工具身份变化。

| 场景与指标                 | 固定基线 | 上一阶段 |   候选 |
| -------------------------- | -------: | -------: | -----: |
| 冷生成墙钟（秒）           |     2.86 |     2.58 |   2.60 |
| 冷生成 CPU（秒）           |    12.51 |    12.20 |  12.26 |
| 冷生成进程树采样峰值（MB） |   885.28 |   696.40 | 696.96 |
| 冷生成单进程系统峰值（MB） |   962.97 |   723.44 | 765.58 |
| 热重建墙钟（秒）           |     2.19 |     1.97 |   1.97 |
| 热重建 CPU（秒）           |     8.46 |     8.29 |   8.27 |
| 无修改墙钟（秒）           |     0.04 |     0.04 |   0.04 |

相对固定基线，冷生成墙钟减少 0.26 秒，CPU 减少 0.25 秒。计时覆盖分析与 Zig 源码生成，分区编译及链接由引导构建另行验证。

首组对照的单进程系统峰值增加 42.14 MB。随后用相同输入交错运行四对，每约一毫秒读取一次系统驻留量及物理内存峰值。复测的系统峰值中位数为 727.62 → 717.23 MB，范围分别为 718.01～765.85 MB 和 715.34～722.45 MB。物理内存峰值出现在输出完成前约 0.30～0.40 秒。两组峰值的变化方向不同，进程树常规采样峰值基本持平。
