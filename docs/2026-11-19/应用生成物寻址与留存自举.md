# 应用生成物寻址与留存自举

## Intent · 目标

把应用构建和监听构建共用的生成物寻址、复用及写出调度迁入 RX/ZX。保持现有构建目录摘要、文件内容、写入顺序和发布门禁。让生成物写出和后端命令共用模块路径。

## Data · 正式调用链

`cli/build.zig` 的 `prepare` 由普通构建及 watch 共用。原来 `artifacts.prepare` 在 Zig 中决定摘要字段、根文件写入和按内容寻址的模块路径。命令组装再次计算每个模块的 SHA-256。已存在的生成文件通过整文件分配来比较。Node 支持文件及 C 适配器也使用同一留存入口。

```mermaid
flowchart LR
    Bundle[借用已生成的应用及类型] --> Identity[ZX 计算构建目录摘要]
    Identity --> Workspace[RX 按顺序写入入口、ABI、宿主和结果]
    Workspace --> Modules[ZX 计算并登记模块路径]
    Modules --> Command[后端命令借用写入时的路径]
```

## Edges · 生命周期与原生边界

保留现有 SHA-256 布局和编译图的 JSON 编码。生成文本和导入描述由调用方持有，Source 读取借用的列。原生宿主继续负责 JSON 编码、Zig 平台文件读取及原子写入。生成响应发布与监听输入核验沿用既有路径。

```mermaid
flowchart LR
    Spec[Source 选择路径与内容] --> Read[逐段比较现有文件]
    Read --> Match{文件内容一致}
    Match -->|是| Keep[保留现有文件和时间戳]
    Match -->|否| Replace[通过原子文件替换]
    Keep --> Publish[交给原有构建与发布]
    Replace --> Publish
```

## Answer · 验收

八组正式回归共通过 93 个构建步骤和 18 项 Zig 测试，覆盖原生后端发布、真实后端协议、C 头文件恢复、普通和 RX 监听、Node 声明与运行、Wasm。Node 另通过 64 项绑定检查和 561 项协议检查，Wasm 通过 489 项运行检查。新 RX/ZX 文件通过格式及 lint 检查。 实际应用重建保留内容一致的文件及其修改时间，截断、增长及等长篡改的生成文件均原子恢复。

从空的应用生成目录分别运行直接对照和候选。普通应用、52 个自定义原生模块、36 个生成模块、普通 C 翻译、C 头文件监听、Node、Wasm 的工作区路径、源码、命令和最终产物一致。产物对照归一化随机暂存路径以及由该路径影响的 Node Mach-O UUID 和签名。初始 seed 与 `7c9b225c3` Source 引导器对同一窄清单生成 26 个 Zig 文件，25 个逐字节一致，其余文件归一化生成的局部变量编号后相同。

macOS arm64、Zig 0.17.0、ReleaseSmall。固定基线为 `e4cec1dc6`，直接对照为 `e65d12cb2`，三套 CLI 均由 `7c9b225c3` 的 Source 引导器构建，运行时使用 Source 分析和生成。实际 Zig 后端编译和链接纳入计时。禁用 zxc 生成缓存，复用同一套后端缓存。版本按轮换顺序执行，首轮预热后取七轮中位数。峰值 RSS 由系统进程计量取得，按十进制 MB 计。

| Node                |          91.42 / 91.09 / 91.04 |      148.29 / 144.27 / 144.68 |           117.42 / 117.03 / 117.00 |

相对直接对照，最大墙钟和 CPU 增量分别约 7.54 ms 和 7.16 ms。相对固定基线，最大累计墙钟和 CPU 增量约 8.34 ms 和 8.54 ms。Wasm 峰值相对直接对照增加 0.74 MB，是六组中最高的 RSS 增量。其他样本的内存变化在 0.33 MB 内。

单独测量留存检查时，将旧整文件比较和当前实际原语编入同一个 ReleaseSmall 探针。每组按版本交错，首轮预热后取七轮中位数。

| 留存样本            |      墙钟（ms） |       CPU（ms） | 峰值 RSS（MB） |
| ------------------- | --------------: | --------------: | -------------: |
| 6,000 次核对 2 KiB  |   64.41 → 63.58 |   63.67 → 62.85 |    1.90 → 1.90 |
| 1,000 次核对 96 KiB | 174.56 → 178.10 | 173.75 → 177.23 |    2.11 → 2.00 |
