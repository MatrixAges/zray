Morphic 报告的 1.48 倍几何平均加速以论文内的 Perceus 式实现为基线。MVS 的动态容器使用写时复制，
Perceus 可以在运行时检查引用是否独占。zxc 采用这些论文的来源、路径和最后使用点分析，并在编译期证明独占。
数组原地更新的分配对照只覆盖研究记录中的具体负载。整程序吞吐量需要按相同算法、分配策略和优化级别与 Rust 对照。
[Morphic §7](fully_automatic_borrow_inference.pdf) · [MVS §6.3](mutable_value_semantics.pdf) · [Perceus §2.4](perceus.pdf)

He 等的 OOPSLA 2026 论文用可达性判断哪些对象能随作用域一起释放。该形式化系统用显式作用域表达回收边界，论文将自动推断和实证评估留给后续工作。zxc 内部可沿用其分析思路，根据阶段输出的可达性决定哪些中间数据值得分配。[When Lifetimes Liberate §3.2、§3.4 和 §7](https://arxiv.org/html/2509.04253v3)

Wu 等于 2026 年 11 月公开的预印本用前向抽象解释验证 Rust 核心子集中的 Polonius。其检查对象是已经存在的借用关系，验证了如何安全地结束和传播这些关系。对 zxc 可借鉴的是按控制流裁剪仍有效的借用事实，函数边界的来源关系仍由 zxc 从普通值和调用推导。[Verified Implementation of the Next-gen Borrow Checking Algorithm for Rust via Abstract Interpretation §4 和 §6](https://arxiv.org/html/2611.06319v1)
