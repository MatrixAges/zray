# genz 工作区与类型列复用自举

## Intent

让普通输出、入口和独立函数的类型工作区使用 RX/ZX 分配和复用。沿完整的获取、使用、退出调用链核对容量、借用列、已写入记录及清理。

## Data

起点为 `f57246c11`。正式函数文件通过 `functionPrepared` 借用生成线程上的工作区，入口和只生成类型的路径使用临时分配区。之前已有 Source 的静态准备顺序和逐行恢复规则，容量、列跨度、临时 ABI 分配和工作区初始化由 Zig 执行。[共同入口](../../packages/genz/src/zx/render.zig) · [复用调用](../../packages/genz/src/zx/modules.zig)

## Edges

沿用一块连续的复用缓冲区、五个类型列和一个已写入行索引列。扩大容量后初始化类型区，复用时仅恢复写过的行。借用同一列，避免每个函数重新计算工作区布局或复制类型项。无需跨线程共享工作区。Zig 保留平台分配、AST 及原生列的 ABI 适配和调用点的退出解除。初始引导器继续走 seed。

```mermaid
flowchart LR
    Output[入口和独立函数] --> Prepare[工作区准备]
    Prepare --> Reuse[容量核对与列借用]
    Prepare --> Fresh[ABI 与状态列分配]
    Reuse --> Lower[生成正文与记录写入行]
    Fresh --> Lower
    Lower --> Reset[恢复已写入行]
```

```mermaid
flowchart LR
    Backing[线程的连续缓冲区] --> Layout[Source 绑定五个类型列和索引列]
    Layout --> Cache[正文生成借用列]
    Cache --> Touched[登记已写入的类型行]
    Touched --> Clearing[退出时恢复这些行并清空计数]
    Clearing --> Layout
```

## Answer

沿生成的 Source 引导器核对首次准备、同容量复用、扩大容量和退出恢复。验证生成后包含的内存操作与原数据表示等价，并比较同一冻结清单、完整引导产物和现有生成回归。宿主保留的 ABI 及资源操作按正式调用闭包记录。

### 已迁移的正式路径

临时 ABI 列及共享类型的三张状态列由 Source 分配和初始化。复用路径由 RX 先核对容量，再调用 ZX 绑定连续缓冲的六个区间。增长时初始化五张类型列，读取缓存时直接借用已绑定的索引列。退出时恢复已写入的行并清空计数。通用缓冲增长、标量填充、切片绑定和宿主退出解除沿用静态原生操作。Zig 对工作区容量、区间布局和逐行恢复的旧实现仅供 seed 使用。

Source 引导器完成 26 个自编译构建步骤。当前源码的主、执行、宿主、集合和增长清单由 `cc6988f0f` 和候选引导器分别生成，17,043 个输出逐字节一致。705 个冻结入口用相同工具链运行三轮交错对照，分区数固定为 16，关闭常驻生成器。三组工具均由 Source 自编译，运行各自的 Source 分析和发射。
