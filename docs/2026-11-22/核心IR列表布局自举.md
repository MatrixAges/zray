# 核心 IR 列表布局自举

## Intent · 最终目标

让正式编译器中的表达式、语句和负载列采用 Source 声明定义的元素类型与标签。分析、联结、所有权和目标生成继续借用同一份 IR 存储。

## Data · 可用证据

起点为 `bf5a1f48e`。正式路径使用的 Source 读写代码从内存接口取得表达式与控制列模型，Zig 的读视图和可增长列又各自声明了一遍元素类型。初始种子编译该接口之前仍需原生布局。[Source 列模型](../../packages/core/interfaces/memory/function_descriptors.d.zx) · [表达式表](../../packages/core/src/expression_table/model.zig) · [控制表](../../packages/core/src/control_table/model.zig)

## Edges · 边界与限制

保留列名称、元素宽度、标签值、缓存编码、预留顺序和既有读写入口。正式编译器从已经生成的 ABI 取得字段类型，初始种子独立构建。可增长列借用同一底层缓冲，类型核对在编译期完成。

```mermaid
flowchart LR
    ZX[ZX 布局声明] --> ABI[已生成 ABI]
    ABI --> Model[核心 IR 读写模型]
    Model --> Analysis[分析与联结]
    Model --> Output[所有权与代码生成]
    Seed[初始种子布局] --> Stage0[初始引导器]
    Stage0 --> ABI
```

```mermaid
flowchart LR
    Values[表达式或控制记录] --> Append[写入现有列缓冲]
    Append --> View[借用只读视图]
    View --> Validate[校验与消费]
```

## Answer · 验收

先确保初始种子与正式编译器可分别构建。在同一候选上验证表达式、控制与工件读写，并对照引导产物、冻结清单与冷暖性能。

### 正式路径

正式 `core` 模块直接引用当前编译器生成的内存 ABI。表达式种类、集合操作、变换、单目与双目运算符及语句种类取得 Source 的枚举类型。只读表从 ABI 取得列类型，可增长表从只读列推导数组的元素类型。列名、顺序与表示在编译期核对。既有读写入口继续操作同一份切片和分配，没有引入转换缓冲。[IR 布局](../../packages/core/src/ir/schema.zig) · [表达式存储](../../packages/core/src/expression_table/storage.zig) · [控制存储](../../packages/core/src/control_table/storage.zig)

正式编译器、前端、RX 和 genz 共用同一个核心模块实例。初始引导器使用独立的核心模块及原生布局，因此能生成正式布局所用的 ABI。此次对照确认六种枚举的成员名及序号与先前原生定义一致。[构建绑定](../../packages/compiler/build.zig) · [初始引导器](../../packages/compiler/build/bootstrap_tool.zig)

### 集中验收

- Zig 0.17.0、ReleaseSmall、16 分区。上一阶段 Source 引导器构建候选，25/25 个步骤通过。初始 seed 的词法生成目标 21/21 通过。候选引导器 SHA-256 为 `9c65581646cf24cf39bf863f5d957d45ad191a5f67ae962868bc7d2e04c99836`。
- 用候选引导器重建同一五组输入。16,657 份引导文件逐字节一致，工具身份戳单列。
- 九组既有回归运行 232 个构建步骤、593 项测试，全部通过。覆盖模块生成与工件、类型推导、所有权与缓存、库联结、嵌套集合和匹配。

### 性能对照

冻结清单含 735 个入口。两代引导器均由 Source 生成，运行时也走 Source 分析与发射，关闭生成常驻服务。两代交替运行三次。11,753 个生成文件和所有权 memo 载荷一致。下表用中位数，RSS 为进程树采样峰值。

| 路径   | 比较            |  墙钟（秒） |     CPU（秒） |  峰值 RSS（MB） |
| ------ | --------------- | ----------: | ------------: | --------------: |
| 冷生成 | 上一阶段 → 候选 | 2.62 → 2.61 | 13.09 → 13.03 | 664.16 → 667.03 |
| 热生成 | 上一阶段 → 候选 | 1.92 → 1.92 |   8.25 → 8.28 | 646.43 → 645.69 |
| 无改动 | 上一阶段 → 候选 | 0.03 → 0.03 |   0.03 → 0.03 |     0.15 → 0.56 |
| 冷生成 | 固定基线 → 候选 | 2.82 → 2.61 | 12.43 → 13.03 | 884.77 → 667.03 |

两轮验收记录中的 CLI 后端构建单步均为约 2 分钟、峰值约 4 GB。引导器的对应单步从约 28 秒变为 27 秒，峰值均为约 1 GB。上述单步采用各轮回归配置和构建器报告精度。
