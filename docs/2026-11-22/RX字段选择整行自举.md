# RX 字段选择整行自举

## Intent

沿正式字段选择入口一次接通来源类型登记、投影、逐字段合并和最终覆盖检查。退出选择专用的 Zig 投影和应用分流，并把本批实测记入长执行计划。

## Data

普通轮和最终轮共用选择就绪性查询。选中请求后，专用 Zig 投影入口负责验证来源、登记声明字段、调用生成投影，然后经另一个专用宿主调用应用循环。普通、开放与重放字段已经共用 Source 读写。本批将两次调用收束为一个源码入口。

```mermaid
flowchart LR
    Ready[选择已就绪] --> Apply[Source 选择入口]
    Apply --> Types[按顺序登记声明成员]
    Types --> Projection[投影字段]
    Projection --> Unify[逐字段合并]
    Unify --> Coverage[最终覆盖检查]
```

```mermaid
flowchart LR
    Borrow[借用来源字段和图列] --> Project[沿原规则生成投影]
    Project --> Target[解析目标字段]
    Target --> Merge[合并并刷新借用]
    Merge --> Target
    Merge --> Result[交付结果或原位置诊断]
```

## Edges

一次选择借用原字段及临时区。声明成员按原来顺序全部登记后求投影，未决来源继续等待，最终轮检查空投影及非空结果。合并后刷新图，错误跨度沿用请求的位置。初始 seed 路径单独验收。

## Answer

删除 `selection/project.zig` 和 `selection/application/host.zig`，正式选择入口直接借用单次请求的暂存区和字段列，执行来源校验、声明成员登记、投影、合并和最终覆盖检查。诊断的规则与文本由 ZX 提供，报告器使用原请求跨度。共享图仍由原拥有者写入，依照 Source 的选择顺序刷新视图。[整行选择](../../packages/compiler/src/rx/analysis/inference/selection/apply.rx) · [字段推进](../../packages/compiler/src/rx/analysis/inference/selection/application/advance.rx)

定向生成确认应用请求直接借用名称、值和索引列，循环输入与状态使用栈上值。选中的字段集合沿用投影本身的既有分配。

候选通过 83 个构建步骤、153 项正式 Zig 测试和 17 项 CLI 集成，包括来源和结果诊断、RX 推导与分配失败。初始 seed 通过解析器构建及 39 项 RX 回归。
