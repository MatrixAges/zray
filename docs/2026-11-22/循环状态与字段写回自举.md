# 循环状态与字段写回自举

## Intent · 最终目标

循环状态声明、循环帧、借用字段布局及字段更新的发布由 Source 推进。把字段类型解析、名称拥有与复用规则移出正式 Zig 遍历。

## Data · 可用证据

循环生成器已经返回列，但 `iteration/state.zig` 和 `iteration/frame.zig` 仍决定跟踪标记、守卫、前缀和入口分支的写回。字段准备还在 Zig 逐项解析类型。字段布局、字段投影及赋值需要让临时生成的名称延长到最终 AST 的生命周期。

## Edges · 边界与限制

跟踪标记须在声明后发布。循环守卫先写表达式与退出行，再写前缀和循环入口。字段源表继续借用，名称只为需要跨临时分配区的值保留字节。旧 seed 保留同语义的初始引导行为。

```mermaid
flowchart LR
    I[循环计划及状态] --> F[字段类型解析 ZX]
    F --> G[Source 生成 AST 列]
    G --> P[RX 按声明、帧、布局或赋值发布]
    P --> T[最终 AST 与循环分支]
```

```mermaid
flowchart LR
    N[名称与来源列] --> S[选择借用、拥有或复用]
    S --> R[保存需要拥有的字节]
    R --> C[在目标列登记]
```

## Answer · 交付与验证

核对正式入口及失败顺序，以循环、类型投影、缓冲转移和字段更新回归、引导产物一致性与固定性能清单验收。

### 实现

状态声明先发布原声明，再按是否启用跟踪发布标记。循环帧按守卫、已有前缀、循环语句和可选入口分支的顺序交付。两条路径直接借用生成结果，在导入各列时适配其表示。

借用字段布局直接遍历类型表中现有的字段类型切片，逐项解析后写入原输出缓冲。布局与投影共用字段发布流程，只让生成的绑定名和拥有的来源名进入最终分配区。投影和布局都直接更新最终名称列，省去临时整列复制。

字段赋值在 ZX 中按生成的来源索引选择借用、拥有或复用，先准备名称再提交表达式与语句。顺序依赖沿用原规则，同一来源的第二个位置复用前一位置的字节。宿主仍提供底层名称分配、原有列导入和字段存储接口。

### 一致性与性能

候选采用 Zig 0.17.0、ReleaseSmall、16 个引导分区，构建通过 25/25 步骤。候选引导器 SHA-256 为 `e334b2641a2d426940957680b90c4383e0100ce86b335621f09eef8e81d1adf4`。主清单、增长、集合和执行四组共 16,201 份再生成产物逐字节一致，排除记录工具身份的 `.zxc-inputs`。五个小清单入口的生成代码未引入堆分配、扩容或数据复制。

固定清单含 735 个入口。两套工具均由 Source 引导器生成，并执行各自的 Source 分析与生成。相同配置下交替运行三轮。下表是中位数，RSS 单位为字节。

| 工具     | 冷墙钟（秒） | 冷 CPU（秒） | 进程树峰值 RSS | 单进程峰值 RSS |
| -------- | -----------: | -----------: | -------------: | -------------: |
| 固定基线 |         2.82 |        12.43 |    884,768,768 |    934,051,840 |
| 上一阶段 |         2.60 |        12.97 |    662,323,200 |    680,656,896 |
| 本阶段   |         2.58 |        12.93 |    662,765,568 |    684,883,968 |

较上一阶段，冷墙钟减少 0.02 秒，冷 CPU 减少 0.04 秒，进程树峰值增加 0.44 MB，单进程峰值增加 4.23 MB。采样物理内存峰值中位数下降 10.99 MB。相对固定基线，冷墙钟减少 0.24 秒，CPU 累计增加 0.50 秒，进程树峰值减少 222.00 MB。热墙钟由 1.92 秒下降至 1.91 秒，热 CPU 减少 0.02 秒。无改动运行均为 0.03 秒。冻结清单的 11,753 份产物和所有权缓存载荷一致，两代工具各自的冷暖产物也一致。

### 回归与余项

循环列、模块化循环、字段所有权、函数更新、循环初值、原生借用和对象累积通过 449/449 构建步骤和 966/966 项测试。十个改动的 RX/ZX 文件通过 lint。原始记录位于 `.zig-cache/verification-tmp/loop-state-publication/`。

本批退出 Zig 的职责包括状态和循环帧发布顺序、布局字段逐项解析、布局与投影名称发布、赋值名称来源遍历。宿主仍负责列导入、结果缓冲存储和拥有文本的分配。接续循环表示的进入与退出、初值转换、借用字段重建和结果恢复。
