# genz 表达式作用域自举

## Intent

贯通普通、值 ABI 和迭代表达式的作用域进入、结果优先求值、逆序绑定降低、正序 AST 发布和退出回收。

## Data

普通与值 ABI 共用 Zig 的 `lowerMode`。状态与栈成员已有 Source 登记，绑定遍历重新解码局部作用域行。迭代作用域从 Source 取得成员候选，再在 Zig 逐项查找和写回。两路绑定把求值前后的使用状态交给各自逻辑解释。

```mermaid
flowchart LR
    Scope["表达式作用域"] --> Enter["登记布局和迭代成员"]
    Enter --> Result["先降低结果或尝试末项融合"]
    Result --> Reverse["Source 给出逆序绑定及读取方式"]
    Reverse --> Publish["按源码顺序发布 AST"]
    Publish --> Restore["恢复别名和新增成员"]
```

## Edges

复用别名先于结果和绑定求值生效。成员登记记录本层成功添加的键，退出时只移除这些键。末项迭代融合成功时消费末项，失败时沿普通路径求值。绑定名是否使用必须在相应子表达式执行前后分别读取。Task 保持启动和清理顺序。

```mermaid
flowchart LR
    Before["Source 借用绑定和使用列"] --> Request["返回下一个绑定请求"]
    Request --> Child["递归降低表达式"]
    Child --> After["读取更新后的使用标记"]
    After --> Rows["发布绑定或丢弃 AST"]
```

## Answer

普通、值 ABI 和迭代共用逆序绑定请求。Source 从借用的 IR 列选择复用、跳过、Task、丢弃及普通或值 ABI 求值。迭代发布前，通过 Source 读取求值后的使用标记、名称和类型。普通和值 ABI 由 Source 定位供末项融合尝试的绑定和结果表示。已有登记与别名恢复规则继续服务这条调用链。

迭代作用域由 Source 选出本层需要新增的符号。合并插入与错误捕获的原型将成员列降为只读切片，安装时无法复用原有的可写表。最终实现将完整键列表一次交给现有成员表的插入原语。宿主提交已选的键，失败时只回收成功前缀，正常退出时回收本层新增键。宿主也继续递归降低子表达式和安装 AST 区间。[自举收敛计划](自举收敛计划.md)

### 阶段产物

候选由 `4123c6f02` 的 Source 引导器构建，25 个构建步骤通过。初始 seed 重新构建并生成 lexer，14 个构建步骤通过。候选按同一配置重新生成主清单、growth 和 collections，14,365、462 和 84 份文件分别逐字节一致，工具身份戳除外。

十一组回归共通过 513 个构建步骤、957 项 Zig 测试和 3 项 Node 集成检查。迭代调用套件包含编译和库封装阶段的分配失败枚举，行为回归覆盖嵌套作用域、状态别名、退回原值和 Task 清理。

两代 CLI 关闭缓存生成 27 个现有夹具，嵌套缓冲、迭代调用及分支作用域的 Zig 输出均逐字节一致。

候选引导器 SHA-256 为 `f5d5b596ccc5a9adb88a8986a26f131753f410075f9e40b3c45450c84453724c`。原始记录位于 `.zig-cache/verification-tmp/genz-scope/`。
