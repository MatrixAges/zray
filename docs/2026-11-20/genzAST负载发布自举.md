# genz AST 负载发布自举

## Intent

让选中行与密集行的实际遍历、写入顺序及失败发布由 Source 执行。两条路径直接写入底层列的预留尾部，保留既有借用和复制语义。

## Data

Switch、引用提升及捕获降低会将已有 AST 视图中的部分行导入目标。每个标签的行共享同一组物理负载列。密集导入可以整列复制，选中行须按引用顺序写入，失败时只公布完整前缀。旧密集路径先复制一份临时负载列，再将值写入目标。

```mermaid
flowchart LR
    View["已验证的来源列"] --> Reserve["预留目标列尾部"]
    Reserve --> Mode["RX 选择导入事务"]
    Mode --> Dense["复制密集列"]
    Mode --> Selected["按标签与偏移写入选中行"]
    Dense --> Publish["发布负载长度和行头"]
    Selected --> Publish
```

## Edges

密集导入的失败仍保留原始可见长度。选中行导入失败时丢弃当前未完成行，发布已成功复制的前缀。文本可以按既有生命周期借用，局部 arena 中不能转移的负载仍按需要复制。物理容量与释放使用内部通用内存原语。

```mermaid
flowchart LR
    Copy["复制到未公布的尾部"] --> Failure["某列复制失败"]
    Failure --> Leaf["释放本次写入的负载"]
    Leaf --> Policy["由 Source 应用恢复规则"]
    Policy --> All["密集路径放弃整批"]
    Policy --> Prefix["选中路径发布成功前缀"]
```

## Answer

密集行的首轮遍历将数据写入预留尾部。遇到失败时，Source 释放先前完成的组；成功后发布负载长度并重定位行头，减少一份临时列描述符和到目标列的再次写入。选中行由 Source 按原有标签和偏移读写，每次只提交完整负载组。失败后由同一个 RX 入口发布已完成行的行头前缀。[发布编排](../../packages/genz/src/analysis/node_headers/payload/append.rx)

借用适配器在通用列读写规则下连接两种导入，保留物理容量预留和布局检查。复制原语直接处理字节列、文本与必要的内层切片；一组内失败时释放已写值，列长度仍在旧位置。普通导入、Switch、引用提升、捕获和迭代均通过共用导入入口。初始 seed 保留原生的发布次序。[物理列借用](../../packages/genz/src/node/import_payloads.zig) · [通用列传输](../../packages/core/src/memory/column_transfer.zig)

候选由上一批 Source 引导器生成，以 Zig 0.17.0、ReleaseSmall 和 16 个生成分区构建，25 步通过。初始词法 seed 的 14 个构建步骤也通过。主清单、增长清单和集合清单的 14,401、464 和 97 份文件分别比较，共 14,962 份生成文件与上一批工具在同一输入上逐字节一致。

八组既有回归共 368 个构建步骤、1,216 项 Zig 测试与 33 项 Node 集成检查全部通过。覆盖求值顺序、循环规则与编译分配失败、Store I/O、函数效果、类型化 Try 库、纯谓词分配、原生引用库，以及 Task 捕获在源码和库中的执行。CLI 集成构建复用已校验的本地 Zig 归档。候选引导器 SHA-256 为 `ab1fb26b7b7a3fed4073b616ee7d6b87ec38b8a6e5b2fb3d76d93e7a84cbfa8b`。

### 性能

三个工具均由 Source 引导构建，启用 Source 分析及生成。macOS arm64、Zig 0.17.0 ReleaseSmall、固定 735 个入口、16 个分区，关闭常驻生成。三轮交错运行取中位数，测量源码分析与 Zig 生成阶段。

| 场景与指标                     | 固定基线 | 上一批 |  本批 |
| ------------------------------ | -------: | -----: | ----: |
| 冷生成墙钟（秒）               |     2.82 |   2.62 |  2.61 |
| 冷生成 CPU（秒）               |    12.37 |  12.53 | 12.61 |
| 冷生成进程树采样峰值 RSS（MB） |    885.2 |  710.0 | 714.3 |
| 冷生成单进程峰值 RSS（MB）     |    921.6 |  744.5 | 737.7 |
| 热生成墙钟（秒）               |     2.24 |   1.97 |  1.97 |
| 热生成 CPU（秒）               |     8.42 |   8.20 |  8.23 |
| 无修改生成墙钟（秒）           |     0.04 |   0.03 |  0.03 |

较上一批，冷生成墙钟减少 0.01 秒，CPU 增加 0.08 秒，进程树采样峰值增加 4.3 MB，单进程峰值下降 6.8 MB。较固定基线，冷生成墙钟减少 0.21 秒，CPU 累计增加 0.24 秒，进程树采样峰值下降 170.9 MB。

候选与上一批在固定清单上的 11,753 份冷生成文件一致，候选自身冷暖生成也逐字节一致。相邻两批的所有权缓存 SHA-256 均为 `cdf9fa7e0f33002a95dc097b2837de781d67e6e519a452fb97f89f7c0bbf3a23`。

### 剩余工作

宿主仍提供静态类型布局、容量预留和必要的底层复制。递归求值的宿主执行沿普通函数、值 ABI 和迭代入口继续收拢。[自举收敛计划](自举收敛计划.md)
