# genz 正文遍历与作用域自举

## Intent

把函数正文的反向遍历、分支顺序和作用域边界移到 Source，逐步消除 `Lower` 中的编译器专用调度与状态。保持现有 AST 和 Zig 产物，保留表达式、Store、任务和终值处理的求值顺序。

## Data

`Lower.function` 调用 `statements.lower`。旧路径在 Zig 中打开块作用域、反向处理语句，并在分支处递归。每个块的入口登记状态符号和栈符号，出口还原。分支先降低条件，再依次降低真、假分支，最后合成 AST。终值与前一条绑定是否融合依赖实际降低结果。`Switch` 的默认分支先于命名分支降低，比较或字面量标签的生成位置取决于选择形态。

```mermaid
flowchart LR
    IR["借用控制与表达式列"] --> Plan["Source 规划反向语句区域"]
    Plan --> Actions["进入作用域、语句段、分支条件、汇合、退出"]
    Actions --> Emit["执行现有表达式与原子语句降低"]
    Emit --> AST["提交 AST 区间并恢复作用域"]
```

## Edges

相邻普通语句合并成一个反向区间。分支事件只保存块位置和操作，复用 IR 属性和 AST 列。存活的作用域共用工作区，空块按原规则交付空区间。融合成功才跳过前一条绑定，失败或成本过高时保留原绑定。失败时按活动作用域逆序清理符号。初始 seed 沿用原生路径。

```mermaid
flowchart LR
    Enter["登记符号并借用区间槽"] --> Run["降低当前语句段"]
    Run --> Child["按事件执行子块"]
    Child --> Join["发布分支和区间"]
    Join --> Leave["移除本块符号并复用槽"]
    Run -->|失败| Leave
    Child -->|失败| Leave
```

## Answer

正式正文在 RX 中选择整块或多分支路径。ZX 生成分段指令列、确定嵌套块与活动作用域的容量，并批量撤销块中登记的符号。`If` 依次降低真分支和假分支，`Switch` 先降低默认分支，再倒序降低命名分支。选项的比较和字面量仍在原来的 AST 生成位置。旧的 Zig 递归正文与 `Switch` 遍历只在初始 seed 中执行。

正式 Zig 路径顺序执行 Source 指令，保留单段内的原子语句派发、终值融合成功时的相邻槽跳过、临时列分配和 AST 写入。分支条件、标签和普通表达式仍通过 `Lower` 递归降低，后续随表达式作用域和缓存迁移处理。[自举收敛计划](自举收敛计划.md)
