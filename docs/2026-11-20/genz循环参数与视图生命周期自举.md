# genz 循环参数与视图生命周期自举

## Intent

贯通普通循环、投影循环、值 ABI 和集合操作的作用域进出。由 Source 保存和写入循环形参名称、选择测试顺序和集合操作数的表示，并沿正式入口核对失败恢复。

## Data

参数计划已在 Source 查询原有符号。Zig 原先读取并写回名称列，分别删除每个新增符号。普通循环和投影循环各自维护一次循环体求值前后的视图。集合接收者和参数的表示由宿主按操作种类选择。

```mermaid
flowchart LR
    Lower["循环正式入口"] --> Enter["Source 参数计划与名称绑定"]
    Enter --> Step["Source 条件、回调和写回计划"]
    Step --> Evaluate["执行递归求值"]
    Evaluate --> Result["更新、循环帧与返回值"]
    Result --> Restore["恢复符号和名称"]
```

## Edges

参数名称为借用的字符串描述符。导入时捕获原描述符，使循环退出后恢复原名。成员删除维持条件参数、步进参数的顺序，同一参数槽至多登记一次。符号插入逐项提交，保留第二项分配失败时对第一项的清理能力。解除投影与延迟列表视图仍由持有指针的宿主完成。

```mermaid
flowchart LR
    Saved["原名称和符号事实"] --> Enter["写入循环名称"]
    Enter --> Optional["按计划检查初始投影条件"]
    Optional --> Scoped["安装循环体视图"]
    Scoped --> Eval["依次降低条件与回调"]
    Eval --> Close["恢复视图并发布更新"]
    Close --> Release["退出时释放本层符号并还原名称"]
```

## Answer

RX 先查询符号，再由 ZX 直接写入名称列并返回恢复所需的数据。恢复和投影首测使用同一名称写入入口。循环计划携带条件、可选初次测试和回调，投影及普通循环共用递归求值作用域。集合操作数的类型选择在 Zig 编译期执行 Source 规则。实际递归调用、写回 AST 的安装、借用视图指针和分配失败处理继续由宿主承担。[自举收敛计划](自举收敛计划.md)

符号恢复沿用逐项的 Source 删除。尝试批量删除时，同清单有 22 份文件出现多余取址或相应的生成差异，四处错误导致 Zig 编译失败。用独立冷生成对照，恢复原删除入口后产物重新一致。通用批量接口在循环作用域下的状态恢复仍需单独核对。
