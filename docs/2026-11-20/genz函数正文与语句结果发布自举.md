# genz 函数正文与语句结果发布自举

## Intent

普通函数和值 ABI 共用 Source 的正文执行与输出规则。语句段消费融合结果时由 Source 更新游标和行区间。合并引用区间的行头和可见长度一起发布。

## Data

编译器先生成正文，再生成契约检查，前置声明需要两者记录的资源信息。最终输出先放前置声明及 Store 初始化，再放引用块、契约、正文与 Store 提交。语句融合尝试可能回退，只有成功时才跳过前一个绑定。

```mermaid
flowchart LR
    Function["普通函数与值 ABI"] --> Plan["RX 决定执行与输出顺序"]
    Plan --> Execute["执行正文、契约及 Store 阶段"]
    Execute --> Spans["已生成的 AST 区间"]
    Spans --> Publish["Source 写入行头并提交可见长度"]
```

## Edges

保留执行次序、错误次序、分支融合条件和空区间行为。执行计划在编译期展开。底层 AST 行和列的存储仍由现有 Zig 内存接口持有。

```mermaid
flowchart LR
    Cursor["反向语句游标"] --> Emit["执行该行"]
    Emit --> Result["区间及融合结果"]
    Result --> Commit["Source 发布当前区间"]
    Commit --> Next["按融合结果清除前项并更新游标"]
```

## Answer

`Lower.function` 的正式路径由 RX 决定普通函数与 Store 函数的执行顺序和输出排列，生成的顺序在 Zig 编译期展开。原调度只供初始 seed 使用。语句段和分支汇合共用 Source 结果写回。AST 连续区间、引用间接区间和块合并复用同一行头与可见长度发布契约。[正文编排](../../packages/genz/src/analysis/functions/body/plan.rx) · [语句结果提交](../../packages/genz/src/analysis/statements/traversal/commit.zx) · [AST 区间发布](../../packages/genz/src/analysis/node_headers/block/publish.zx)

候选由上一批 Source 引导器生成，以 Zig 0.17.0、ReleaseSmall 和 16 个生成分区构建。Source 引导构建 25 步、初始词法 seed 构建 14 步均成功。分别比较主清单、增长夹具和集合夹具的 14,393、464 和 97 份生成文件，合计 14,954 份，均与上一批逐字节一致。

契约、Store I/O 和发布、求值顺序、迭代调用与 CLI、类型化 Try 库、循环策略和函数效果共九组回归通过。合计 310 个构建步骤、1,276 项 Zig 测试，迭代返回别名与 Store 初始化器的迁移及重新发布集成检查也通过。候选引导器的 SHA-256 为 `d4b255f56bf1082d5e651d75a44894d701a448b85e416f504ca584a19682764b`。

安装版回归所用的 Zig 0.17.0 macOS arm64 官方归档已通过校验。本地留存同一份归档供后续 `-Dzig-archive` 复用，避免每批重新下载。归档 SHA-256 为 `b607e9b9234790a008116ae5bdb71c6243b84b9fb42a53a9e70fde41c06c536a`。

### 性能

三个工具均由 Source 引导构建，运行时使用 Source 分析和生成。macOS arm64、Zig 0.17.0 ReleaseSmall、固定 735 个入口、16 个分区，关闭常驻生成。三轮交错运行取中位数，覆盖源码分析与 Zig 生成阶段。

| 场景与指标                     | 固定基线 | 上一批 |  本批 |
| ------------------------------ | -------: | -----: | ----: |
| 冷生成墙钟（秒）               |     2.79 |   2.56 |  2.58 |
| 冷生成 CPU（秒）               |    12.34 |  12.54 | 12.48 |
| 冷生成进程树采样峰值 RSS（MB） |    887.7 |  711.1 | 713.8 |
| 冷生成单进程峰值 RSS（MB）     |    966.3 |  736.1 | 732.3 |
| 热生成墙钟（秒）               |     2.18 |   1.91 |  1.95 |
| 热生成 CPU（秒）               |     8.36 |   8.03 |  8.18 |
| 无修改生成墙钟（秒）           |     0.03 |   0.03 |  0.03 |

较上一批，冷生成墙钟增加 0.02 秒、CPU 减少 0.06 秒，热生成 CPU 增加 0.15 秒。冷生成进程树采样峰值增加 2.6 MB，单进程峰值下降 3.8 MB。较固定基线，冷生成墙钟减少 0.21 秒、CPU 累计增加 0.14 秒，进程树采样峰值下降 173.9 MB。

候选与上一批在固定清单中的 11,753 份冷生成产物一致，候选自身冷暖生成也逐字节一致。相邻两批的所有权缓存内容 SHA-256 均为 `cdf9fa7e0f33002a95dc097b2837de781d67e6e519a452fb97f89f7c0bbf3a23`。
