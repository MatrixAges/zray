# genz 向量化生成与 AST 发布自举

## Intent

让迭代消费者和集合变换共用一条完整的 SIMD 生成路径。在 RX 中连接准入和表达式分析、字面量求值、向量与尾部发射、AST 发布及结果包装。

## Data

起点为 `cbdade1cc`。分析、发射和发布原先分开生成，正式 Zig 入口保存计划、操作数、编号基址及发布结果，通过多个回调往返传递。

```mermaid
flowchart LR
    Consumer["迭代消费者"] --> Start["RX SIMD 入口"]
    Map["集合变换"] --> Start
    Start --> Analyze["Source 分析与准入"]
    Analyze --> Operands["源值、类型与两趟字面量求值"]
    Operands --> Emit["向量块与标量尾部发射"]
    Emit --> Publish["通用 AST 列发布"]
    Publish --> Result["返回表达式编号或列表表示"]
```

```mermaid
flowchart LR
    Columns["借用 IR 与类型列"] --> Plan["表达式计划"]
    Plan --> Buffer["共享同一字面量缓冲的两个视图"]
    Buffer --> Fragment["表达式列和有序语句片段"]
    Origin["操作数求值后的 AST 基址与捕获"] --> Fragment
    Fragment --> Commit["追加列并提交序列号和分配器标记"]
```

## Edges

按向量、尾部两趟求值，保留缓存读取、错误顺序与原有结果包装条件。两段字面量借用同一个缓冲，AST 基址在操作数完成后读取。表达式列先追加，语句片段按向量、尾部和外层顺序追加，最后提交序列号及分配器需求。分析和发射暂存共用一次调用的 arena。

## Answer

正式生成入口直接执行 `analysis/simd/execute/run.rx`。`simd_plan`、`simd_emit`、`publish_simd` 三个独立入口，以及 Zig 的专用计划帧、逐项操作分类和发布状态退出正式调用链。普通 AST 行声明为发射、打印和实体列写入共用，生成代码直接传递列引用。宿主保留类型与 IR 借用、基址快照、实体列追加与列表结果表示。

使用 `cbdade1cc` 的 Source 引导器构建 ReleaseSmall 候选，主清单使用 16 个分区。372 项编译器测试通过。批首与候选对当前五份引导清单生成的 17,802 个文件逐字节一致，比较排除输入戳。

八组应用回归通过，构建汇总为 368 个步骤和 282 项测试。覆盖 SIMD 机器码与浮点尾部、标量回退、WASM、普通和聚合迭代、列布局、Map 和 Filter 回调顺序、浮点 Reduce 及错误捕获。

固定基线、批首和候选均由 Source 引导器生成，运行 Source 分析与生成。冻结清单使用 Zig 0.17.0、16 个分区，关闭常驻生成。以下为三次交错冷生成的中位数。

| 引导器                             |   墙钟 |    CPU | 采样进程树峰值 RSS | 单进程峰值 RSS |
| ---------------------------------- | -----: | -----: | -----------------: | -------------: |
| 固定基线 `declaration-preparation` | 2.11 s |  9.0 s |          737.62 MB |      760.02 MB |
| 批首 `cbdade1cc`                   | 1.94 s | 9.44 s |          522.49 MB |      551.53 MB |
| 候选                               | 1.94 s | 9.38 s |          521.81 MB |      543.95 MB |

较批首，冷墙钟持平，CPU 减少 0.06 秒。采样进程树峰值减少 0.67 MB，单进程峰值减少 7.59 MB。采样物理占用峰值增加 2.97 MB，系统物理占用高水位减少 7.00 MB。较固定基线，冷墙钟减少 0.17 秒，CPU 增加 0.38 秒（4.2%），进程树峰值减少 215.81 MB。

热生成墙钟保持 1.44 秒，CPU 增加 0.05 秒。无修改生成墙钟与 CPU 均保持 0.03 秒。冻结清单的冷暖生成和批首对照均有 9,894 个文件逐字节一致。
