# 编译库联结与安装自举

## Intent

让源码导入、RX Call 和显式库加载共用一条 Source 联结及安装路径。将导出索引
分配、类型重映射准备、计划接收及安装顺序迁入 RX/ZX，退出两阶段之间的 Zig
数据转换与专用调用。

## Data

批首是 `d81b1545f`。三个入口进入 `compiled/host/root.zig::loadPrepared`。
宿主先分配类型编号和可选导出索引，执行 `compiled_library`，解读数字状态，
再根据计划重新绑定类型尾部、原生模块、函数和公开接口后执行 `compiled_publish`。
原生与函数列描述符可以在规划前借用，类型范围的大小已有 Source 写入能力。

## Edges

保留调用方提供的索引、默认扫描与主动选择多导出时的索引构建顺序。计划与准备
使用原暂存所有者，公开接口和函数使用原交付所有者。计划拒绝不发布数据，准备
失败保持旧错误分类，物化失败继续向宿主交付已完成的函数前缀。

## Answer

正式入口只调用 `compiled_library`。`compiled_publish` 的独立生成入口、宿主
安装调用、附带容量的导出索引描述符和数字状态转换已退出。宿主仍借用现有
列与分配器，并在异常解绕时发布已经写完的函数前缀。类型、函数和接口都复用
原有写入原语，类型范围大小由 Source 按计划填写。

### 验收

- 372 项 Source 编译器回归与 39 项初始引导配置的 RX 回归通过。
- 五份清单的 17,703 个同输入生成文件逐字节一致。
- 210 项应用回归通过，另有 22 项 CLI 项目和编译包检查通过。
- 用安装版运行重新发布回归，通过 4 项检查，覆盖导出重命名、重复选择、路径
  缺失、损坏输入保护和仅类型接口。
- 非 seed 包源码 Zig 新增 124 行、删除 166 行，全仓新增 124 行、删除
  167 行。固定起点 `4c11902b6` 至本批，两项累计净减 3,571 / 2,226 行。
