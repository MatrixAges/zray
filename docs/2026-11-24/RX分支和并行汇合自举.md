# RX 分支和并行汇合自举

## Intent

把 Switch 分支与 Parallel 汇合的检查、目标行计算和发布接入现有 RX 流程。
保留回退标签的求值顺序，避免标签校验为同一程序另建描述表。

## Data

批首为 `bc1d8ad9f`。推导和 IR 降低共用 `project/flow/traversal/run.rx`。
`completeFlowBranch` 在 Zig 中分派 Switch 和分支收尾，`closeFlowParallel`
同时处理推导作用域和降低步骤。`selection.zig` 为每次 Switch 校验分配表达式
视图及根编号临时数组。Seed 保留独立引导路径。

## Edges

先执行分支检查与作用域汇合，再公开对应步骤。分支块分配成功后按原次序写回
行和收回局部绑定。扫描回退标签仍只留所需语法，错误位置和首次失败保持一致。
复用编译结果中的程序指针和列存储。

```mermaid
flowchart LR
  Input["正式推导与 IR 降低"] --> Stack["RX 帧遍历"]
  Stack --> Branch["Switch 分支与覆盖检查"]
  Stack --> Parallel["Parallel 结果汇合"]
  Branch --> Publish["发布对应步骤与分支行"]
  Parallel --> Publish
```

```mermaid
flowchart LR
  Rows["现有标签程序列"] --> Read["借用表达式与结果根"]
  Read --> Check["ZX 检查标签与重复项"]
  Check --> Result["覆盖结论或首次失败位置"]
```

`closeFlowParallel` 的 Zig 分派，以及 Switch 标签检查的两份临时数组。
索引准备改为一次调用 RX，由 RX 遍历事件并选择每步操作。Return、Task、
Parallel 和 Switch／If 分支复用原有行写入接口。Switch 和 If 直接借用
XML 属性与子行，并在 Source 中完成分支容量预留、行写入及发布。原
`prepare/selection.zig`、独立生成入口和四个专用写回回调已移除。
普通 Task 输出保持指向解析树属性的借用。Parallel 与 Switch 的发布区间
复用降低帧已有的区间字段，退出两套独立区间读取。

最小清单的索引准备入口通过通用行缓冲分配所需的分支行，交接描述及写回不另行

固定性能对照尚待本批收口。

操作次序。属性扫描进入 Call 准备入口的直接依赖，旧阶段表与独立扫描入口已

Task，并由 ZX 组装隐式输入路径。路径只分配一次，随原调用输入保留。宿主

扫描入口退出。扫描借用节点名称列，仅匹配后借用 XML 属性。Store 在正文前
处理，Type 在正文后处理，保留两者与正文诊断的先后顺序。Store 初始化器直接
