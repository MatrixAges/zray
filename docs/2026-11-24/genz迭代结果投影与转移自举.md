# genz 迭代结果投影与转移自举

## Intent

让普通和缓冲迭代结果按 Source 的投影计划执行转移、填入读缓存并选择最终求值。普通读路径共用规划与执行，缓冲投影合并计划、资源准备与序列保留，循环结果在同一 RX 入口选择和应用完结策略。

## Data

起点为 `629cd9a37`。Source 已给出投影、转移槽及其复用计划，正式 Zig 路径仍逐项执行。缓冲投影在发射前按操作物化资源、保留序列及记录当时的转移历史边界。

```mermaid
flowchart LR
    Plan["Source 迭代结果计划"] --> Apply["RX 应用"]
    Apply --> Transfer["ZX 复用或转移"]
    Transfer --> Cache["ZX 逐项填入读缓存"]
    Cache --> Eval["RX 选择最终求值"]
```

```mermaid
flowchart LR
    Path["缓冲投影路径"] --> Resources["按操作物化资源并保留序列"]
    Resources --> View["借用最新的转移历史"]
    View --> Emit["发射与发布 AST"]
    Emit --> Unwind["退出后回收临时读缓存"]
```

## Edges

保持每行先求投影再决定是否复用转移槽。新转移的首次返回值与后续复用值有各自的契约。直接投影可提前返回。原生作用域负责回收投影缓存，包含中途分配失败与最终求值失败。宿主继续持有实体 AST、转移表、缓存和资源缓冲。

## Answer

沿普通和缓冲迭代结果集中验证转移、读次数和失败回收。用同一输入核对引导产物，并对照固定清单的冷暖生成与峰值内存。

- ZX 执行转移和读缓存的两个逐行算法。RX 先处理直接投影与缓冲分支，完成缓存填充后选择值 ABI 或普通表达式。原生保留物理槽、缓存读写与作用域解绕，失败时继续回收投影键。
- 普通读取共用规划、长度类型物化与求值入口。缓冲投影以同一个入口构建计划并准备布局、序列和历史边界。外层完结直接调用 Source 策略，减少一次 Zig 计划交接。seed 直接使用原有 seed 投影。
- 使用 `629cd9a37` 的 Source 引导器构建 ReleaseSmall 候选，主清单使用 16 个分区。372 项编译器测试通过。五份清单除输入戳外，17,895 个生成文件逐字节一致。
- 同一批首引导器生成当前源码的应用。九组回归共 564 个构建步骤、947 项测试通过，覆盖迭代调用、缓冲、产品转移、循环列、初始所有权、聚合和模块循环及对象规约。

固定基线、批首和候选均由 Source 引导，运行 Source 分析与生成。冻结清单使用 Zig 0.17.0、16 个分区，关闭常驻生成。下表为三次交错运行的冷生成中位数。
