# zray 越界写法治理清单（5 类逃生口子销项台账）

> 目标：严格遵守 [AGENTS.md](../../AGENTS.md) 核心架构红线，围绕“**RX 编排、ZX 无副作用原子化、`<Store>`（`.store.rx` + `$store.*`）承载跨调用运行时状态**”的设计原则，彻底清除超越 zray 语言特性的逃生口子。所有修复必须遵循**正向自举原则**（逻辑/状态迁入 RX/ZX/`<Store>`，严禁退回手写 Zig），且禁止以代码行数作为评价指标。
