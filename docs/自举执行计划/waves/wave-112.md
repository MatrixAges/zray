## 集成与所有权

- 生成请求的目录遍历、文档分类、接口绑定、指纹和快照发布由 RX/ZX 编排。Darwin 的 `std:fs.readdirMetadata` 通过 `getattrlistbulk` 读取文件，并提供纳秒级 `ctime_ns`。过渡引导器从更新后的标准库声明生成。Compiler 的共享标准库模块从 execution 取得 `std:crypto/blake3` ABI。
- Genz 的调用参数、迭代资源、语句选择改用显式 Store。移除 `StatementTraversal` 和两个手写 Zig 文件。独占或可转移的新数组允许原位 `.with()`，可证明不逃逸的记录使用栈槽，盒装更新直接构造新记录。
- Core 移除 `TextSlots`、`RowBuffer` 和失效的 `core/owned_text` 源码注册。两个缩减后的声明文件仍服务容量和文本所有权调用。只读列视图借用行存储。生成器和 seed 在宿主返回擦除类型的指针时恢复对应的只读名义类型，已具名的指针继续按原类型检查。正式函数表发布的生成入口未出现 `allocator.create`。
- CLI 通过 Store 发布 scope 结果，移除 `Observation` 句柄。Pkgs 和 Lint 将依赖解析和格式规则迁入 RX/ZX，删除 ZX 缩进、长度及 RX 布局的三个旧 Zig 实现。CLI 的版本快照保持可写切片类型，快照比较和 Pkgs 的工作区组图按生成 ABI 传入值记录，原有子字段继续借用。
