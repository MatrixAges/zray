# RX 语句写入与作用域归并自举

## Intent · 目标

把已降级流程写入 IR 时，直接使用 RX 返回的调用范围、控制动作和退出标志，删除语句帧的十六个原生回调。Task 输出的求值、定义、恢复和发布共用现有 RX 语句规则。

## Data · 证据

起点为 `2cdf07ab0`。相关语句、控制流、链接、表达式、捕获和 Store 写入共核对 29 个 Zig 文件、3,092 行。正式入口从 `program/statements.zig` 进入 `statements/traversal.zig`。旧路径每步复制五个状态槽位，再借助不透明指针回调同一宿主。初始 seed 则直接写有类型的 IR。项目已有的 `statements/plan.rx` 明确规定三种 Task 输出的执行顺序，可以在编译期展开。

```mermaid
flowchart LR
    A[已降级的语句列] --> B[RX 识别连续调用与下一操作]
    B --> C[分配好的 IR 写入位置]
    B --> D[Task 输出或分支结束]
    D --> E[RX 绑定与作用域规则]
    E --> C
```

## Edges · 边界

Root 的返回值保留原有借用条件。Case 先完成 IR 写入才恢复绑定，Task 的新结果在恢复父作用域之后发布。嵌套 Case 的写入位置用索引跨越栈扩容。失败保留原错误，沿已有清理路径恢复作用域。源列直接借用，本批不引入额外事件表。

## Answer · 验收

检查新旧 Source 工具在同一源清单上的全量生成结果，用现有真实顺序和并行工程检验返回、绑定与失败路径。分别核对初始引导可构建、源码阶段一致性、固定输入性能与实际剩余原生职责。

### 实现与核查

RX 先取连续 Call 的结束行，再按真实区域解释下一行，返回子区域、标签位置、返回值借用和退出标记。两种引导路径共用同一份有类型的写入代码。Task 结束时，通过已有的 `statements/plan.rx` 在编译期选定步骤：只有需要计算输出的 Task 读取表达式，只有需要对外发布的 Task 读取名称，无需从多列存储重建整条步骤记录。

构建清单、分区及源码接口同时移除 `rx_statement_frame`。宿主直接接收 Zig 错误，取代中间的状态码和不透明帧指针。用户表达式内联、类型化 IR 表存储和有类型的活动帧仍有手写实现，继续列为待迁移职责。

遍历返回复合值，生成器为输入选择了按值传递的布局。接线时改用编译器已有的 `columns.invoke` 静态适配；正式路径调用 `executeValue`，分配器容量为零。从原始 seed 生成的下一代工具与上一代 Source 工具在新遍历入口产生的 13 个文件逐字节一致。所有行号和切片复用原始列。

在本批最终 Source 工具和上一阶段 Source 工具上，765 个入口、5,531 个模块产生的 12,982 个可比较文件逐字节一致，排除的 `.zxc-inputs` 只记录运行路径。12,981 个生成 Zig 文件均不再引用旧的语句帧包及其原生回调。两版 v18 所有权缓存载荷共 14,323,517 字节，SHA-256 均为 `32594ef0cf7527bfbacc4e24bcaa308d5ba05793713cd710b66d8cce8c2602de`。

已有的 RX Task 输出、顺序运行、并行运行和并行推导四组回归共 1,119 项通过，包括嵌套 Case 返回、外层值借用、并行结果发布及出错后释放。相对起点，本批 Zig 新增 50 行、删除 378 行，净减 328 行。RX 与 ZX 合计新增 91 行、删除 437 行，净减 346 行。
