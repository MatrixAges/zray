# 编译库链接流程自举

## Intent · 目标

沿 `zx/modules/link.zig` 的正式入口贯通依赖排序、类型登记、逐模块绑定、程序发布和 IR 验证。用一个有类型的入口处理依赖与根模块，移除专用的 `artifact_view` 外部包及两个原生回调。

## Data · 依据

依赖图已提供拓扑顺序、根模块和依赖区间。正式路径重复准备根模块的提供方列视图，依赖路径还会借用不透明句柄并经 C 回调发布函数。字段映射要在签名绑定完成后读取，函数表尾也要在预留容量完成后借用。无正文的依赖若带 Store，旧分支会索取一个不存在的正文。

## Edges · 边界

同一行的签名绑定、索引重映射、函数发布按序执行。正文继续通过独占的生成入口写入已预留的列。临时内存按行回收，返回值及最终程序使用结果 arena。seed 保留独立实现，用于初始引导与对照。

## Answer · 交付与验收

```mermaid
flowchart LR
    G[依赖图排序] --> T[登记可达类型]
    T --> B[按序绑定依赖和入口]
    B --> P[发布程序]
    P --> V[校验 IR]
```

```mermaid
flowchart LR
    D[拓扑序与入口] --> R[选择当前模块]
    R --> A[验证接口并建立映射]
    A --> F[按映射发布正文或保留入口]
    F -->|成功的依赖| R
    F -->|入口| P[类型表、函数表、导出和 Store]
```

使用同配置引导器生成并构建候选，运行现有编译库与链接回归。复用已有的多模块依赖链比较链接结果、实际耗时及峰值；核实无正文 Store 依赖通过正式入口返回错误。

### 正式调用与源码

从起点 `1dfcd40d3` 追踪库链接、模块图、类型登记、接口绑定、正文重映射与结果发布，涉及 30 个 Zig 文件、2,756 行原始实现。链接的五个阶段由 `workflow/link.rx` 描述并在编译期展开。`workflow/row.rx` 从有序依赖区间选取当前索引及下一位置，依赖耗尽时选择入口。生成的行选择函数按值返回索引，对描述符和依赖区间只读，函数体没有申请内存。

绑定所有模块共用一组提供方列视图。每行完成接口和签名后，才借用最终映射与函数表预留位置并调用独占的正文发布入口。依赖行完成后回收临时内存。带 Store 的依赖在 RX 准备阶段返回错误，对无正文的模块也生效。生成清单的外部接口从五项减为四项，保留 `zxc_string`、`memory`、`memory/columns`、`lexical_path`。物理列借用、内存所有权、IR 列表与程序描述符仍有手写 Zig 实现。

按本批文件的实际增删计算，Zig 增 124 行、删 186 行，净减 62 行；RX 增 39 行、删 40 行，ZX 增 21 行、删 145 行，两者合计净减 125 行。原始调用链范围包含沿用的实现。

### 验证结果

- 上一阶段的 Source 引导器构建候选通过 38/38 步，初始 seed 引导通过 36/36 步。两条引导路径对两个新入口生成的 9 个可比较文件一致。最终 Source 工具 SHA-256 为 `5ef76bfcc91d8cebc380d94007c093530b48bab520114536b940c8e4da1c408d`。
- 新旧 Source 工具对当前 766 个入口、5,505 个模块生成的 12,805 个文件逐字节一致，排除记录运行路径的 `.zxc-inputs`。12,804 个生成 Zig 文件中均已退出旧外部包和回调。
- 既有的链接边界、原生接口、编译库导入、源码与编译库执行、语义缓存、所有权和混合库七组回归通过 114/114 步与 168/168 项测试。独立 128 模块链的前后两版生成同一 Zig 程序，SHA-256 为 `3b835e64650bb1d3da3dfe5ed58e46f8a2e7c03bdd1df901c9f3a620d39c146c`，输入 7 实际运行得到 135。
- 独立调用正式 linker，按模块路径选中非入口的叶依赖，保留一行 Store 并移除正文，确认返回 `InvalidModule`。首次手工复现误选到了根模块，改为按路径定位，避免把入口自己的 IR 校验错误误作依赖校验结果。

### 链接性能

复用 128 模块依赖链。上一提交和候选都使用 ReleaseSmall 的 Source 分析与链接实现，每组执行 120 次链接，两版交替七组，取中位数。墙钟仅覆盖链接循环，CPU 与 RSS 覆盖整个探针进程。

| 指标           | 历史固定对照 |     上一提交 |         本批 |
| -------------- | -----------: | -----------: | -----------: |
| 链接墙钟       |    107.49 ms |    104.51 ms |    103.34 ms |
| 进程 CPU       |    190.26 ms |    184.00 ms |    182.92 ms |
| 单进程峰值 RSS | 17,465,344 B | 17,399,808 B | 17,399,808 B |

较上阶段墙钟减少 1.16 ms，CPU 减少 1.08 ms，峰值内存持平。与历史固定对照相比，墙钟减少 4.15 ms，CPU 减少 7.33 ms。这组数据只反映编译库链接，整仓冷构建沿用既有基线。
