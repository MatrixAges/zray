# 硬件图构造与端口展开自举

## Intent

让硬件图的工作区准备、输入写入、定义解析与来源跟踪、输出树展开及安全条件确认由 Source 推进。

## Data

硬件入口从符号执行取得输入、按顺序登记的定义和输出。之前的 Source 路径已负责符号绑定、单条定义的类型规则和 SMT 项读取。内部图的阶段推进和输出递归仍在 Zig。[硬件入口](../../packages/compiler/src/backends/hardware/root.zig) · [定义发布](../../packages/compiler/src/backends/hardware/construction/definition.rx)

```mermaid
flowchart LR
    Symbolic[符号模型及类型列] --> Reserve[预留图与索引]
    Reserve --> Inputs[输入节点及符号]
    Inputs --> Definitions[按序解析定义及记录来源]
    Definitions --> Outputs[展开复合输出并核对类型]
    Outputs --> Safe[确认布尔安全节点]
    Safe --> Graph[交付硬件图]
```

## Edges

保留预留和逐条执行顺序、错误优先级和分配器。连续相同来源只复制一次，输出解析前清空定义来源。借用原类型和符号值，Zig 持有物理节点、索引和端口存储。

## Answer

验证原有语义、资源失败、Verilog 字节及 HDL 仿真。复用冻结引导输入及硬件阶段性能对照。

### 实现

正式入口由 RX 先预留图和索引，再登记输入、逐条解析定义、展开输出并确认布尔安全节点。ZX 负责端口类型解析、定义来源复用和输出树递归。宿主仍持有节点、索引、端口和固定分配器，并为构造阶段提供读写接口。
[正式编排](../../packages/compiler/src/backends/hardware/construction/workflow/run.rx) · [存储接口](../../packages/compiler/src/backends/hardware/construction/workflow.zig)

定义循环直接借用符号表里的名称、表达式和宽度列，复用节点已有的来源记录。输出校验读取类型列和标量属性。两处的生成函数都能直接用这些借用数据执行，不需要为每条定义或递归步骤分配临时对象。

排查输入绑定时，探针记录到容量已成功从零扩到 16。原始优化产物却以零长度描述符调用哈希定位。LLVM IR 将来自只读原生句柄的索引写入参数标记为 `readonly`，随后以初始值替代读取。现在句柄指向只读的指针槽，槽内保存可写的图状态指针，使宿主回调通过可写指针更新索引。

### 验收

候选引导器通过 25 步构建，二进制与上一阶段相同，SHA-256 为 `7fce570df79ac26433d4ac472cc64ce12d8a575273770898fd0cbd58fae69fd0`。使用候选重新生成主清单、所有权增长、集合和符号执行清单，15,915 份文件与构建时产物逐字节一致，排除工具身份戳。

硬件资源、HDL 仿真、验证资源、验证和契约通过 91 个构建步骤及 14 项 Zig 测试。硬件资源覆盖输入、复合输出和两种 RTL 形态的分配失败清理。Yosys 数值对照覆盖组合和时序路径。

### 性能

macOS arm64、Zig 0.17.0、ReleaseSmall，停用 CLI 缓存和常驻生成。两套 CLI 由 Source 引导器生成并使用 Source 分析及发射，候选通过新 RX 路径构建硬件图。对照提交为 `0f0631c0f`。同一组输入和求解器交错运行，预热一轮后取七轮中位数。六组配置的 Verilog 和 JSON 都逐字节一致。RSS 为 CLI 进程的系统峰值。

| 输入                 | 墙钟旧 → 新（毫秒） | CPU 旧 → 新（毫秒） |  峰值 RSS 旧 → 新（字节） |
| -------------------- | ------------------: | ------------------: | ------------------------: |
| 组合逻辑复合端口     |        10.02 → 9.94 |         9.12 → 9.10 |   24,985,600 → 24,985,600 |
| 4,096 字段，真实 Z3  |       36.42 → 34.14 |       35.62 → 33.24 |   26,509,312 → 26,492,928 |
| 512 分支，真实 Z3    |     450.27 → 448.25 |     449.09 → 447.09 | 200,114,176 → 200,114,176 |
| 时序逻辑复合端口     |         9.99 → 9.85 |         9.16 → 9.00 |   24,985,600 → 24,985,600 |
| 4,096 字段，隔离求解 |       31.38 → 29.27 |       30.15 → 28.12 |   17,940,480 → 17,989,632 |
| 512 分支，隔离求解   |     446.21 → 445.47 |     444.73 → 443.99 | 200,097,792 → 200,114,176 |

配对样本的墙钟和 CPU 中位数均下降，峰值 RSS 最大增加 48 KiB，出现在隔离求解的宽对象用例。固定引导清单沿用哈希相同的引导器。较固定基线，冷生成墙钟低 0.25 秒、CPU 高 0.49 秒、进程树峰值低约 223.8 MB。本批未单独测量完整 Zig 冷构建。[固定清单证据](引导输出树和分区发布自举.md)
