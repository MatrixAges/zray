# 清理自举产物

从仓库根目录运行 `python3 scripts/clean_build_artifacts.py`。默认预览六小时前的候选。确认范围后，用相同参数加 `--apply`。报告卷的实际可用空间，避免把单个目录的逻辑大小当成已释放空间。

1. 先查当前构建、核验和清理进程及其输出。已有清理在运行时继续观察它的进度。对活跃路径、当前可复用的 Source 工具和固定性能基线，各传一次 `--keep <路径>`。核验工作目录会逐项筛选输出，优先保留具体输出目录以便回收同级旧产物。已有核验结论、提交、配置和必要的产物哈希留在 `docs`。
2. 清理仓库内过期的核验目录、Zig 缓存及 Git 忽略且未被文档引用的中间文件。保留源码、Git 工作树、文档正文、用户记录、固定 Zig 工具链和仍被使用的证据。目录近期写入或用途不明时先保留该路径，继续处理已确认过期的其他候选。
3. 约每六小时做一次检查。遇到大批构建前空间不足，也可以提前检查。清理完成后确认保留的工具仍可用。如果空间目标尚未达到，按目录核对剩余占用，继续处理确认可再生成的历史产物。达到某个空间数字后仍应处理剩余的过期候选。
